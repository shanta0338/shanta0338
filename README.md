## 🧠 About Me

I am a **Software Engineering graduate specialising in Data Science** from **Daffodil International University**, with a strong interest in building efficient and reliable AI systems.

My current research interests centre around:

* **Natural Language Processing (NLP)**
* **Retrieval-Augmented Generation (RAG)**
* **Agentic AI and multi-step reasoning**
* **Small Language Models (SLMs)**
* **Resource-efficient and privacy-preserving AI**
* **Weather Forecasting**
* **Quantum Computing**

I am particularly interested in designing AI systems that are not only accurate, but also **efficient, verifiable, and practical in resource-constrained environments**.

📄 I am the author of a preprint on an **Agent-Verified RAG architecture using Small Language Models**, currently under peer review.

## 🔬 Research

### Agent-Verified RAG with Small Language Models

My undergraduate thesis focused on developing an **agent-verified Retrieval-Augmented Generation framework** for resource-constrained environments.

Key areas of work included:

* Designing dual-retrieval and verification pipelines using **LangGraph**
* Exploring multi-step reasoning and agentic verification
* Working with **Small Language Models (SLMs)**
* Evaluating Context Relevance, Faithfulness and Semantic Similarity
* Benchmarking on **MS MARCO, TriviaQA, HotpotQA and 2WikiMultiHop**
* Analysing inference and pipeline latency

📄 **Publication**

**An Agent-Verified System for Resource-Constrained Query-Focused Summarisation using Small Language Models**

*Shanta Majumder · Suprove Chandra Sarkar*

Preprint: Research Square / ResearchGate
Currently under review in *SN Computer Science*

## 🌍 Open Source

### `pytorch-forecasting`

I contribute to open-source machine learning infrastructure and documentation, with a focus on **deep-learning-based time-series forecasting**.

Current contributions include:

* Reproducible API usage examples and executable doctests

## 🚀 Selected Projects

### 🌦️ Global Weather and Location Prediction Engine

A machine-learning system for predicting locations from meteorological data.

**Tech:** Python · PyTorch · Scikit-learn · Pandas · Streamlit

* Feature engineering and meteorological data preprocessing
* MLP-based prediction model
* **77% classification accuracy**
* Interactive Streamlit deployment

---

### 📰 Fake News Detection using NLP

An NLP-based system for classifying news articles as real or fake.

**Tech:** Python · spaCy · Scikit-learn

* Text preprocessing and semantic feature extraction
* Compared Random Forest, Gradient Boosting, KNN and Multinomial Naïve Bayes
* **90% classification accuracy using Gradient Boosting**

---

### 🧬 Multiple Diseases Prediction

An ensemble machine-learning system using a **Stacking Classifier**.

**Tech:** Python · Scikit-learn · Optuna · Streamlit

* Automated hyperparameter optimisation
* Random-search-based model optimisation
* **96% classification accuracy**
* Interactive web deployment
